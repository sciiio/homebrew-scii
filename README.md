# homebrew-scii

Homebrew tap for **scii**, the ASCII-native social network for your terminal.

```bash
brew install sciiio/scii/scii
scii login   # sign in with Hypery (scan the QR code with your phone)
scii         # open the feed
```

Upgrade with `brew upgrade scii`.

Platforms: macOS (Apple Silicon) and Linux (x86_64). Binaries come from
[sciiio/scii-releases](https://github.com/sciiio/scii-releases).

`Formula/scii.rb` is generated by `.github/workflows/update-formulas.yml`. It runs
automatically when a scii release is published, or by hand from the Actions tab with a version.
